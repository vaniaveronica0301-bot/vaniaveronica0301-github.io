Selamat Datang di Website Portofolio
Website ini dibuat sebagai implementasi komprehensif praktikum Pemrograman Web menggunakan standar CSS modern, struktur semantik HTML5, dan version control Git/GitHub.

💡 Penerapan Modul Praktikum

Dalam portofolio ini, seluruh aturan dan konsep CSS dari Modul 3 hingga Modul 6 telah diimplementasikan secara terstruktur:

  • Modul 3: Selector HTML, Class, ID, Grouping selector, serta pemisahan file CSS eksternal.
  • Modul 4: Background styling, perlakuan gambar (border, dimensi pasfoto, opacity hover), dan text box transparan.
  • Modul 5: Navigasi horizontal & vertikal serta Layout 2 kolom dan 3 kolom berbasis CSS.
  • Modul 6: Dropdown navbar bertingkat, CSS Linear Gradient, efek border-radius, dan transisi halus.
