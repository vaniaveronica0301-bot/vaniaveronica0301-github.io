MODUL 3: Dasar CSS, Selector, dan Grouping

Penerapan Selector HTML, Class, ID, Grouping, serta tag SPAN dan DIV

1. Selector HTML & Class

Mendefinisikan gaya pada elemen tag spesifik dan class yang dapat digunakan kembali.

Teks .headlines
Teks .sublines dengan warna teks abu-abu tua.
Teks .infotext bergaris miring untuk catatan.

2. Selector ID & Tag DIV

Penggunaan ID unik untuk elemen struktural seperti #menu, #hero, dan #wrapper.

Contoh Layer DIV

Tag <div> sebagai blok dan <span> sebagai inline tag.

3. Grouping Selector

Menggabungkan deklarasi CSS beberapa selector sekaligus untuk efisiensi kode.

h1, h2, h3 { font-family: 'Segoe UI'; }
.headlines, .sublines { ... }

✓ Kode bersih & mudah dikelola

MODUL 6: Dropdown Navigation, Gradient & Border Radius

Penerapan CSS Linear Gradient, sudut melingkar (border-radius), dan transisi dropdown menu

Fitur Lanjutan Modul 6 yang Diterapkan:

🌈 Linear Gradient

Gradient dua warna pada navbar dan hero banner: linear-gradient(135deg, #1e3c72 0%, #2a5298 100%).

🔘 Border Radius

Memberikan efek rounded corner halus pada tombol, card, foto profil, dan sub-menu dropdown: border-radius: 8px.

⚡ CSS Transitions

Transisi halus saat hover pada tombol, menu navigasi, dan efek pasfoto: transition: all .25s ease-in-out.
